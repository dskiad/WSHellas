Secretary

The document office of the Chapter. Every document is drawn under the letterhead, sealed, signed as the rule requires, and issued as a PDF — or as a Word file, to be perfected before it is issued.

Every PDF the Chapter issues is protected and opens only with the Chapter's security code. Choose Word when a document is still being worked on; the Word file carries no code and can be edited freely.
